# Eng Sir Alex Irungu — Portfolio Website

A responsive, multi-section portfolio starter using HTML, CSS and vanilla JavaScript.

## Open the website
1. Extract `my-portfolio.zip`.
2. Open `index.html` in a modern browser. For local development, use VS Code with the Live Server extension.
3. Open `cv.html` to view the editable starter CV. Use **Print / Save as PDF** to create a PDF.

## Update your portfolio
- **About/profile photos:** add your images into `images/` and replace the placeholder blocks in `index.html` with `<img src="images/profile.jpg" alt="Alex Irungu">`.
- **Videos:** add MP4 files into `videos/`, then add a `<video controls>` element where you want a demo.
- **Projects:** use the website's “Add a project” form. New project cards are saved in the browser's localStorage. For permanent public updates, edit `index.html`/`script.js` and redeploy.
- **Learning journal:** use “Write a journal entry.” Entries and milestones are saved only in that browser on that device. They do not automatically sync between devices or appear to other visitors.
- **CV:** edit `cv.html` with your current details, then print/save as PDF.
- **Contact details:** currently set to alexdimple58@gmail.com and +254 700 909 851. WhatsApp uses the international format +254700909851.

## Publish online
Upload the folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Keep `index.html`, `style.css`, `script.js`, and `cv.html` together at the site root. No build step is required.

## Important notes
- The project cards contain starter descriptions. Update project status and details to match the actual state of your work.
- The vein-visualization item is clearly presented as a concept, not a validated medical device.
- Forms save to local browser storage only. A real contact form, multi-device content management, analytics, or cloud-backed journal would require a backend or external service.
- Replace all placeholders with your own approved photos and actual evidence before sharing widely.
